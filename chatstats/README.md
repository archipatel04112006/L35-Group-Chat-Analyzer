## Introduction
Group Chat Analyzer is a Linux Shell Scripting project. It analyses chat messages and generates useful statistics.

## Features
1. Messages per person
2. Most active hour
3. Top 10 words
4. Longest message
5. Chat statistics report
6. View chat data
7. Backup data
8. View activity log

## Linux Commands Used
- awk
- cut
- sort
- uniq
- tr
- grep
- tar
- cron

## Folder Structure

- lib/functions.sh
- data/chat.txt
- reports/
- backups/
- logs/
